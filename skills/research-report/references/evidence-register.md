# Evidence register template

Use one row per source or claim-bearing artifact:

| id | source/locator | retrieved | scope | excerpt/artifact | status | claims supported | conflict/limits |
| --- | --- | --- | --- | --- | --- | --- | --- |
| S-001 |  |  |  |  | not-yet-checked |  |  |

Use `trusted` only when the applicable first-party or method review supports
that status. `provisional` means usable with a visible caveat, not confirmed.
`rejected` sources remain in the register when their rejection explains a
decision. `unavailable` means the route or body could not be accessed.

For every major report claim, add a short mapping to one or more source IDs and
label the claim as evidence, inference, assumption, recommendation, or open
question. Preserve the as-of date and the method used to resolve conflicts.
